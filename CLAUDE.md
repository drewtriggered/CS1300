# CS 1300 coursework

Drew's Python exercises, midterm and final for CS 1300 at Indiana Tech. Each `.py` file is a standalone exercise, run with `python3 <file>`; there are no tests or dependencies.

## Rules

- This is graded coursework. Explain and guide; don't rewrite a whole exercise unless Drew asks for that.
- Keep solutions at an intro-course level: plain functions, loops and conditionals, standard library only.
- Don't rename or move exercise files, and leave README.md as it is (it is saved as UTF-16).

## How this file improves itself

Run `/lessons` at the end of a session. It reviews the session for corrections and mistakes, proposes short rules, and adds only the ones Drew approves to the Lessons section below. Keep this file under about 150 lines; move topic-specific rules into `.claude/rules/`.
